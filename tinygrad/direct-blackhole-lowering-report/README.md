# Direct Blackhole lowering report

This snapshot investigates a direct tinygrad-to-Blackhole compiler boundary and
includes the report's rendered forms, experimental patches, logs, and regenerated
UOp evidence.

- [`research-output/technical-report.md`](research-output/technical-report.md):
  canonical Markdown report.
- [`technical-report.html`](technical-report.html): rendered HTML report.
- [`technical-report.pdf`](technical-report.pdf): rendered PDF report.
- [`research-output/ARTIFACTS.md`](research-output/ARTIFACTS.md): artifact index
  and experiment notes.

The original research archive's source snapshots (`tinygrad`, `blackhole-py`,
and `blackhole-py-rewrite`), `metadata/`, and input `uop-dumps/` corpus are not
included in this documentation repository. Report citations are relative to
that original archive, and the captured scripts and validations are preserved
as historical evidence rather than rerunnable repository checks.
